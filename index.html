01 about

Curious by default, hands-on by habit

I like the LAMP stack for how quickly it turns into something real, I like Java for how it makes you think in structure, and I like data because it's the part of a system that tells the truth.

I'm a final-year Computer Engineering student at Datta Meghe College of Engineering, Airoli, Navi Mumbai (University of Mumbai), graduating in 2027. Across three internships I've built a CMS-driven website in PHP and MySQL, written full-stack Java applications with JSP and JDBC, and used SQL for real data extraction and reporting — alongside 6+ database-backed web apps on Java/JSP, MySQL, Firebase and Supabase.

Lately I've been adding generative AI and prompt writing to that mix — partly because the field is moving fast, partly because it changes how I think about every other tool I use.

Beyond code, I volunteer with the National Service Scheme, earned my Ordinary Cadet certification with the Sea Cadet Corps, and recently started contributing to open source through GirlScript Summer of Code (GSSoC'26).
